# 极简追加 Prompt

把下面三行放在任何请求末尾：

```text
干净交付，锁定范围，保留关键理由。
请按当前请求完成并在停止条件处收束。
交付物的标题、文件名、正文、注释和说明呈现最终状态；保留必要的事实限制、验证结果和链接，过程记录另存。
```

## 记忆版

```text
干净交付｜锁定范围｜只报结果｜保留关键理由
```

这四个词适合写进项目根目录的 `AGENTS.md`、团队提示词或个人 Skill。模型能否跨会话识别它们，取决于宿主是否持续加载这份规则。

## English

```text
Clean delivery. Scope locked. Final state in the deliverable. Keep factual limitations, verification results, and links; keep process notes separate.
```
