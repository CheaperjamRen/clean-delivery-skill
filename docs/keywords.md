# 关键词：让规则变得好记

长 Prompt 很难一直复制。把四个词写进 Skill 或 `AGENTS.md`，日常请求里用短语唤回完整规则。

| 关键词 | 交付动作 |
| --- | --- |
| `干净交付` | 标题、正文、代码、文件和回报呈现最终状态。 |
| `锁定范围` | 当前目标和停止条件成为工作边界。 |
| `只报结果` | 回报排列为结果、证据、限制、链接。 |
| `保留关键理由` | 保留读者无法从成果直接得到的理由、边界和失效条件。 |

## 推荐组合

```text
干净交付｜锁定范围｜只报结果｜保留关键理由
```

## 关键词的边界

关键词本身不会写入模型的长期记忆。规则需要由当前 prompt、项目根目录的 `AGENTS.md`、Skill 加载器或系统配置持续提供。遇到高风险、不可逆或需要审计的动作，补上明确的确认点和记录位置。
